# human-in-loop v0.1.3

This release keeps routine progress notifications disabled by default and sends
at most one terminal `notify_human` application message per logical task. The
same compact message contains its durable report locator. HTTP(S) locators use a
quoted, byte-preserving wrapper to suppress large Apple Rich Link Previews;
non-URL paths remain unquoted.

iMessage decisions now use deterministic decimal-only correlation tokens. A
normal token is five digits with no leading zero, and active collisions extend
the same deterministic prefix by two decimal digits at a time. The exact reply
grammar is `<TOKEN>-<OPTION_NUMBER>`, such as `48273-1`. Bare options, the old
hexadecimal-space form, malformed separators, invalid options, stale tokens, and
uncorrelated rows remain fail-closed.

The public MCP surface, rich multiline bodies, explicit iMessage-only/no-SMS
transport, send/watch correlation predicates, Bot/TCC topology, Feishu routing,
canonical HOME migration, daemon lifecycle, and notification result semantics
are unchanged.

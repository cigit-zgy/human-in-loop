# human-in-loop v0.1.1

`v0.1.1` is a release-candidate hotfix for local Codex MCP configuration and
channel-failure diagnostics.

## Fixes

- Install and update remove the known project-managed legacy
  `HUMAN_IN_LOOP_HOME` override while preserving unknown custom homes and all
  unrelated Codex configuration.
- Codex MCP, CLI, and daemon consequently use the same canonical human-in-loop
  runtime configuration.
- `NoAvailableChannel` remains fail-closed and now records coarse, privacy-safe
  availability reasons for popup, Feishu, and iMessage candidates.

This task prepares the candidate only. It does not publish a tag or release.

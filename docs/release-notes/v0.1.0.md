# human-in-loop v0.1.0

`v0.1.0` is the first independent public source release of human-in-loop, a
small bridge for coding agents that need a real human decision or a terminal
task notification away from the computer.

## Highlights

- Local stdio MCP exposes exactly two tools: blocking semantic decisions with
  `ask_human`, and non-blocking informational delivery with `notify_human`.
- The maintained remote path includes Apple Messages through explicit
  iMessage-only delivery with SMS fallback disabled.
- The production macOS path uses a dedicated Bot macOS user signed into a
  distinct Bot Apple Account and communicates with the primary coordinator
  through narrow authenticated local IPC.
- One-time bootstrap establishes a stable local code identity and macOS privacy
  permissions. Qualified normal operation and routine updates are unattended.
- The release path was qualified with a genuine iPhone notification, structured
  reply, strict correlation, and one canonical result.
- Codex integration asks only at unresolved semantic checkpoints and sends one
  compact terminal notification when a task finishes. Periodic/progress
  notification is deferred beyond `v0.1.0`.

## Known boundary

After a Mac reboot, the dedicated Bot graphical session must be logged in once
before Apple Messages can become ready again. The runtime reports that recovery
state rather than silently falling back to another transport.

## Distribution

This is a source release. GitHub's generated source archives are the release
artifacts. It does not include or claim a notarized downloadable macOS installer
or general binary distribution.

Upstream AskHuman adaptation and the external `openclaw/imsg` dependency are
credited with pinned coordinates in [`THIRD_PARTY.md`](../../THIRD_PARTY.md).

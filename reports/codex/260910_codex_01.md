## AI-assisted implementation transparency

Codex generated the implementation and tests under the committed ChatGPT design. The central implementation choice was to use public, read-only host inspection and the native macOS Users & Groups UI rather than capture a password or write undocumented loginwindow state. Control flow is:

```text
setup
→ non-mutating host/target preflight
→ unsupported: safe manual fallback
→ supported and undecided: one canonical ask_human
→ manual: persist minimal non-secret mode
→ automatic: persist intent, open native UI, stop at native-auth checkpoint
→ rerun: verify actual host state without re-asking
```

An initial real-host probe exposed that `dscl . -read ... OriginalNodeName` can exit successfully while returning a missing-attribute diagnostic. Codex diagnosed that platform behavior, replaced it with an explicit local directory-node read, and added the reproducing regression test. No private chain data or credentials were involved.
